## 与现有产业链系统的适配

1. 保留 `HubLayout` 与 `/new-ui/home/production/*` 路由结构；新增生产页面进入同一侧边栏，旧版短路径继续重定向。
2. 保留供应链 Scheduletool、MASA-QMIX、物流资源管控中的多周期车辆路径、外协供应商和知识库的挂载及页面。
3. 保留原有 LLM 提供商配置与显示适配；未用远端环境配置覆盖本地 `.env`。
4. 保留生产执行自动完工、立即完工演示及组装物料就绪衔接。
5. 合并定时事件与自动完工时，增加“事件与完工同一轮到达”的保护：事件先被消费，避免被提前标成 completed 后失去触发机会。
6. 新排程桥接保留完整计划包及候选数据，同时把推荐方案转换为旧助手工具需要的 `schedule_results`，支持后续交期询问和会话复用。
7. 旧工具只读取新版计划包的推荐方案；无推荐或尚待策略确认时不暴露候选为可执行方案，避免最短但违规的候选被旧评分逻辑选中。
8. HTML 缓存清理入口 `/go` 接回产业链主控台，而不是改回上游独立生产系统首页。

本次没有导入远端的虚拟环境、临时目录、演示稿及其 node_modules，也没有导入远端实际数据库或替换本地运行数据。
