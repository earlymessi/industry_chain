# MAQM联合系统：AGV前序场景 + 冰箱组装调度

## 概述

本项目在原有的冰箱组装调度系统基础上，新增了AGV（自动导引车）前序场景，用于物料运输和供应。两个场景通过物料管理系统协调，确保冰箱组装过程的物料充足。

## 系统架构

```
┌─────────────────┐    ┌─────────────────┐
│   AGV前序场景    │    │ 冰箱组装主场景  │
│                 │    │                 │
│ • 物料运输      │◄──►│ • 组装调度      │
│ • 库存管理      │    │ • 物料消耗      │
│ • 路径规划      │    │ • 任务执行      │
│ • 4个AGV智能体   │    │ • 6/8/10个工人   │
└─────────────────┘    └─────────────────┘
         │                       │
         └───────┬───────┘
                 ▼
        ┌─────────────────┐
        │ 物料管理系统     │
        │                 │
        │ • 需求管理      │
        │ • 供应协调      │
        │ • 状态监控      │
        └─────────────────┘
```

## 使用方法

### 1. 运行联合系统测试

```bash
python test_joint_system.py
```

### 2. 训练联合模型

```python
from joint_trainer import JointTrainer

trainer = JointTrainer()
trainer.train(num_episodes=1000)
```

### 3. 运行场景管理器

```python
from scene_manager import SceneManager, SceneMode

# 串行模式：先AGV准备，再组装
manager = SceneManager(mode=SceneMode.SERIAL)
manager.run(max_episodes=10)

# 并行模式：两个场景同时运行
manager = SceneManager(mode=SceneMode.PARALLEL)
manager.run(max_episodes=10)
```

### 4. 前端评估

启动后端服务：
```bash
python api_server.py
```

在浏览器中访问前端，选择"联合场景(AGV+组装)"模式进行评估。

## 运行模式

### 串行模式 (SceneMode.SERIAL)
1. AGV场景运行，准备物料
2. 当物料充足时，启动冰箱组装场景
3. 两个场景按顺序执行

### 并行模式 (SceneMode.PARALLEL)
1. 两个场景同时启动
2. 通过通信通道实时交换物料信息
3. AGV根据需求动态补充物料

### 混合模式 (SceneMode.HYBRID)
根据生产需求动态切换串行/并行模式（预留扩展）

## 物料管理

### 物料类型
对应9种冰箱组装工序：
- CASE: 外壳组装
- COMP: 压缩机安装
- COOL: 制冷系统
- PIPE: 管道连接
- ELEC: 电气系统
- DOOR: 门体安装
- SEAL: 密封处理
- TEST: 质量检测
- PACK: 包装入库

### 库存策略
- 中央仓库：500单位容量
- 分布式存储点：50单位容量
- 自动补货：低库存时触发AGV运输

## 奖励机制

### AGV场景奖励
- 任务完成奖励：+1.0
- 任务分配奖励：+0.5
- 车队利用率奖励：忙碌AGV比例 × 0.1

### 冰箱组装场景奖励
- 原有调度奖励
- 物料短缺惩罚：-50

### 联合奖励
- 总奖励 = AGV奖励 + 组装奖励
- 物料充足性奖励：充足物料类型数 × 0.05

## 技术特性

### 智能体数量
- AGV场景：4个智能体（可配置）
- 冰箱组装：6/8/10个智能体

### 状态空间
- AGV观测：位置、状态、载重、电量、货物信息
- 组装观测：原有观测 + 物料状态

### 动作空间
- AGV：选择待处理任务或空闲
- 组装：原有动作 + 物料检查

## 注意事项

1. **依赖关系**：确保所有新增文件在正确位置
2. **内存使用**：并行模式需要更多内存
3. **训练时间**：联合训练比单场景更耗时
4. **模型存储**：联合模型保存在 `model/joint_training/` 目录

## 故障排除

### 常见问题
1. **环境初始化失败**：检查PyTorch和Gym版本
2. **物料不同步**：检查通信通道配置
3. **训练不收敛**：调整奖励权重和学习率
